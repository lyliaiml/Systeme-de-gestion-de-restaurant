
# Système de gestion de restaurant – SQL

## Présentation

Projet universitaire réalisé en novembre 2025.

Ce projet porte sur la conception et la mise en place d'une base de données destinée à la gestion d'un restaurant.

Il comprend une phase de modélisation, la conception du schéma relationnel et l'implémentation de requêtes SQL.

## Travaux réalisés

- Analyse des besoins
- Modélisation des données avec Merise
- Conception du schéma relationnel
- Création des tables
- Écriture de requêtes SQL complexes
- Mise en place de triggers
- Développement de procédures stockées

## Concepts informatiques abordés

- Modélisation des bases de données
- Modèle conceptuel de données (MCD)
- Modèle logique de données (MLD)
- Langage SQL
- Intégrité et contraintes des données

## Technologies utilisées

- SQL
- MySQL
- Merise

## Organisation du projet

- `src/` : scripts SQL
- `docs/` : sujet, rapport et documentation
